    Alloy の記法の読み方

    記法意味読み替え
    sig A {}もの(集合)の定義「A という種類のものがある」
    sig A { f: one B }関係(フィールド)の定義「A はちょうど 1 つの B を持つ」(lone = 0 か 1 / some = 1 つ以上 / set = 0 個以上)
    abstract sig / extends種類の分類「状態は Pending / Shipped / Cancelled のいずれか」
    fact { ... }常に成り立つ制約「この条件を破る状態は存在しない(前提)」
    pred P { ... }条件に名前を付ける「P という状況」
    assert A { ... } + check A主張を反証で確かめる反例が見つからなければ、その範囲で主張は成立
    run P例の存在を確かめるインスタンスが見つかれば、制約は矛盾していない
    for 5探索範囲(スコープ)「各種類を最大 5 個までの範囲で調べた」(範囲外は未確認)
    all / no / some量化子「すべての〜」/「〜は存在しない」/「〜が存在する」
